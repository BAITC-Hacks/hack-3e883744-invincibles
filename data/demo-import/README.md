# Подготовленные профили для демонстрации импорта

Это **собственные синтетические примеры команды**, не скрытые профили жюри. Производные от [SHAGRA-KIT v1](../synthetic/README.md), без реальных персональных данных.

Войдите как HR, откройте «Импорт», выберите [employees.json](employees.json) и [activity_history.csv](activity_history.csv), нажмите «Проверить файлы», затем отдельно подтвердите применение. Пустая CSV содержит обязательный заголовок: история этих новых демонстрационных профилей пока отсутствует.

| ID | Что показать |
|---|---|
| `DEMO_ACTIVE` | Полный профиль Middle с дефицитами; появляются полезные следующие шаги |
| `DEMO_TARGET_MET` | Требования Senior уже покрыты; приложение не предлагает ненужную активность |
| `DEMO_FINAL_GRADE` | Senior — последний грейд текущего каталога; отсутствие следующего грейда объяснено |
| `DEMO_UNKNOWN` | Нет оценки System Design; приложение не подменяет неизвестный уровень нулём |

Профили используют `role: "Backend Engineer"`, как пример ТЗ. Импорт сопоставляет строку с ID или названием роли в текущем каталоге, включая имеющиеся переводы; канонический `role_id` также принимается. Неизвестные и неоднозначные роли, конфликт `role`/`role_id` отклоняются. JSON — массив; CSV — ровно пять известных колонок в любом порядке. Остальные поля и ссылки проверяются строго.

Повторное применение тех же файлов без промежуточного изменения профилей не начисляет навыки и не дублирует историю. Если вы уже выполнили активность в одном из этих профилей, повторный импорт возвращает его навыки к указанному snapshot; используйте примеры в отдельном демонстрационном окружении.
