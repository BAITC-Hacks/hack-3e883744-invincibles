## Изображения и доказательства

Актуальные изображения интерфейса находятся в [ui/simple](validation/ui/simple/README.md). Файлы `live-*` получены с настоящим backend и синтетической БД; остальные снимки этой папки фиксируют UI-сценарии с подставленными API-ответами. [AI-отчёт](validation/ai.json) и [измерения задержки](validation/latency.json) относятся к указанным внутри них ревизиям и условиям. Текущая сводка проверок — в [TESTING.md](TESTING.md).
