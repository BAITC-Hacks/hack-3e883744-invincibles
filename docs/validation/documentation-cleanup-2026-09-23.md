## Изменения

- Подготовлены связанные README на русском, казахском и английском с изображениями рабочего приложения, установкой, конфигурацией, данными и ограничениями.
- Добавлены навигатор документации, описание архитектуры и инструкции тестирования.
- Убраны устаревшие утверждения о невнедрённом интерфейсе и непроверенном OpenAI; исторические отчёты отделены от текущего состояния.
- Вторая копия требований к редизайну заменена ссылкой на основной документ.
- Удалены восемь неподключённых CSS-файлов и 30 дублирующихся файлов шрифтов/лицензий из `frontend/public/fonts`. Активные WOFF2 и исходные лицензии сохранены в `frontend/src/shared/styles/fonts`; побайтовое совпадение проверено.
- Удалены пустой по смыслу локальный `commit.txt` и воспроизводимые тестовые кэши. `.env`, runtime-БД, lock-файлы, зависимости и материалы защиты сохранены.
- Docker build context исключает документацию, макеты, тестовые отчёты, локальные переменные окружения и промежуточные TypeScript-файлы.
