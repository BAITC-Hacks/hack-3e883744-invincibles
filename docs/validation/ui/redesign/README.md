## Просмотр

На Linux/macOS запустите из корня репозитория `./start-design.sh` — сервер откроет макет в браузере. Остановка: `Ctrl+C`. Другой порт: `./start-design.sh --port 8091`; запуск без открытия браузера: `./start-design.sh --no-open`. Скрипт можно запускать из любой рабочей папки по его полному пути.

Из корня репозитория:

```powershell
.venv\Scripts\python.exe -m http.server 4178 --bind 127.0.0.1 --directory docs/validation/ui/redesign
```

[Профиль](http://127.0.0.1:4178/?view=profile), [HR](http://127.0.0.1:4178/?view=hr). Прототип также открывается локально через `index.html`; сервер нужен для воспроизводимых браузерных проверок.

Выбор ячейки показывает навык, основная кнопка открывает демонстрационное сравнение, «Другой шаг» переключает три сохранённые рекомендации. В HR работают вкладки, поиск по текущей таблице, сортировка первого столбца, страницы и размер страницы. Их состояние хранится в URL. Профиль E0001 доступен в демонстрационном поиске. Разделы навыков и истории показывают тот же снимок данных.

Это инструмент согласования композиции. Выполнение, импорт и авторизация не отправляют запросов и не меняют БД; вспомогательные диалоги явно сообщают об этом. Они не предъявляются как готовая реализация соответствующих сценариев. Рабочие маршруты, все состояния запросов, гарантии повторных операций и полное сравнение A/B будут реализованы после принятия макетов.

## Сверка с референсом

Использован [a3-template.jpg](../../../implementation/a3-template.jpg). Перенесены почти чёрные фоны, слабый перепад поверхностей, тонкие границы, небольшие радиусы, светло-серые данные и акцентная кнопка, квадратная матрица, компактные монохромные полосы. Все 15 цветов соответствуют нормативным tokens без индивидуальных цветов компонентов. Зелёный обозначает только положительную разницу покрытия.

Адаптации, предусмотренные ТЗ:

- В JPEG криптографики и телефонные рамки; здесь реальные карьерные данные, обычная веб-страница и отдельная desktop-композиция с меню 216 px. На планшете меню занимает 72 px, на телефоне разделы постоянно доступны внизу.
- Квадраты навыков крупнее микроматрицы JPEG: каждый навык имеет отдельную область 44 × 44 px для touch и клавиатуры. У E0001 все 20 навыков ниже цели; разные состояния не выдуманы ради красивого узора.
- IBM Plex Sans/Mono, читаемые русские названия, основной показатель 28–32 px и контрастные подписи заменяют неидентифицированную мелкую типографику JPEG. На ширине 320 px показатель покрытия занимает отдельную строку.
- Основное действие в мобильном профиле стоит перед картой; на desktop карта и рекомендация делят строку в пропорции 7/5. Больших пустых декоративных панелей нет.
- HR использует горизонтальные полосы количества сотрудников, а не неподтверждённый временной график. Рядом всегда видны оценённая группа и доля.

Попиксельное сходство с JPEG и субъективный процент соответствия не заявляются.

## Данные и известные зависимости

`data.js` — фиксированный ответ действующего API на синтетическом ките, исходный backend SHA `79ea94bb891d4aef34021e8492ba4e4603c6cec8`. `generate_data.py` создаёт отдельную временную БД через TestClient, выполняет вход сотрудника и HR, получает профиль E0001, рекомендации и HR overview. Ключ AI отключён только в этом процессе. Production БД и `.env` не изменяются. API не вызывается при просмотре макетов.

- Профиль: покрытие 42,9%, 20 известных дефицитов, 0 выполнений. Рекомендация повышает серверный прогноз до 45,7%; разница 2,8 п.п. Все три активности из API, источник «По правилам», причина «AI недоступен» видна рядом.
- HR: 200 сотрудников; 0 без покрытия каталогом, 0 с недостаточными оценками. Без следующего шага 32: 30 на финальном грейде, 1 с достигнутой целью, 1 с выполненными полезными активностями. Это штатные данные, а не ошибки.
- Топ-5 HR сортируется по affected_count, при равенстве — по русскому названию. В таблице дефицитов 60 строк, по умолчанию 10 на страницу. Пропуски, отказы и выполнения участия не смешиваются.
- **A2:** API evidence содержит `Сейчас Grade.MIDDLE; следующий грейд Senior` и `Истории участия в типе EventType.COURSE нет`. Они сохранены как получены внутри раскрытого «Почему этот шаг»; случайных замен строк нет. Перед приёмкой production A2 должен исправить генерацию текстов в `backend/app/recommendations/service.py`.
- **A1:** `hr/overview.no_step[]` содержит role_id без role_name. Для макета названия взяты из реального `data/synthetic/skills.json`, не придуманы. Для production нужны названия из API или доступный клиенту полный каталог; статический словарь из макета переносить в приложение нельзя. Поиск HR также нужно проверить на наличие role_name.

## Проверки

Команда при запущенном сервере:

```powershell
node docs/validation/ui/redesign/capture.mjs
```

Результаты в [validation.json](validation.json):

- 4 целевых PNG; визуально просмотрены все четыре и сопоставлены с JPEG.
- Chromium, Firefox, WebKit × профиль/HR × 320, 390, 768, 1280, 1440 px: 30 проверок ширины без горизонтальной прокрутки всей страницы.
- На 390 × 844 основной CTA занимает y=522–566, нижнее меню начинается на y=783; кнопка полностью видна без прокрутки.
- Клавиатура: выбор навыка, удержание фокуса в диалоге, Escape, возврат фокуса. HR: восстановление вкладки и поиска из URL после обновления.
- 21 проверенная пара цветов проходит WCAG-пороги: обычный текст ≥4,5:1, значимые границы ≥3:1. Декоративные разделители имеют меньший контраст, как разрешено в требованиях.
- Нет ошибок страницы и неуспешных загрузок ресурсов в целевых Chromium-снимках. Шрифты загружаются локально.

Это проверка прототипа, не финальная приёмка приложения. 200% browser zoom, экранная клавиатура, физические устройства, все error/loading/empty состояния, полный reduced-motion сценарий, production build и живой сквозной сценарий нового интерфейса ещё предстоят. Эмуляция WebKit не равна тестированию физического iPhone. Старые проверки production не выдаются за проверки нового интерфейса.

## Воспроизведение ресурсов и следующий этап

При необходимости заново собрать локальные ресурсы и API-снимок:

```powershell
npm pack @fontsource/ibm-plex-sans@5.3.0 @fontsource/ibm-plex-mono@5.3.0 lucide-static@1.47.0 --pack-destination runtime/design-assets --silent
.venv\Scripts\python.exe -X utf8 docs/validation/ui/redesign/generate_data.py
```

Каталог `runtime/design-assets` должен существовать. Версии и лицензии в [assets-manifest.json](assets-manifest.json), полные тексты в `assets/` и [THIRD_PARTY.md](../../../../THIRD_PARTY.md). Снимок для утверждённых эталонов не обновлять автоматически при изменении backend.

После принятия четырёх макетов: перенести tokens и ресурсы в frontend; выделить оболочку, общие компоненты и слои по §10; реализовать маршруты профиля; обновить рекомендации/примерку/выполнение; перенести HR, импорт и вход; подключить все состояния; завершить браузерные и живые проверки по §13. Текущие HTML/JS — прототип проверки, не замена React/TypeScript приложения.
